# 이채원 · 포트폴리오

금융 IT 개발자를 지향하는 이채원의 개인 포트폴리오 사이트입니다.
화면 구현에서 서버·데이터 흐름까지 다루는 개발자로서, 금융 도메인 프로젝트를 중심으로 소개합니다.

**🔗 Live:** https://portfolio-psi-ashen-57.vercel.app/

## 대표 프로젝트
- **사망자 명의 금융거래 신속차단 DB** — 은행 계정계·채널계·정보계 구조를 반영한 금융 DB 설계 (MySQL · 30테이블 · 68 FK · 3NF)
- **TicketRush** — 콘서트 예매 서비스(졸업 프로젝트), 실시간 좌석 동기화·QR 발권·관리자 대시보드 (프론트엔드 담당)
- **WON-pick (Trade 서버)** — 거래 상태머신·멱등 키를 구현한 Spring Boot 백엔드
- **cseetv** — 야간 CCTV 이상행동 감지, 전통 영상처리로 AI(MOG2) 대비 92.1% 성능

## 기술
`HTML` · `CSS` · 단일 페이지 정적 사이트 (프레임워크 없음)

## 실행
이 저장소를 클론한 뒤 `index.html`을 브라우저로 열면 됩니다.
